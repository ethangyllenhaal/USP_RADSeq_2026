# Introduction to RADSeq and dataset selection

The slides for this section are primarily to introduce the kinds of genomic analyses possible with RADSeq, describe the technology, and describe how its basic analysis bears strong similarities to other technologies (e.g., target capture, whole genome resequencing). At the end, students can pick a dataset to analyze.

Not much to put here, but I recommend this paper on the technology: https://www.nature.com/articles/nrg.2015.28
